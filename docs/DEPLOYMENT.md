## 3. Installation Steps

### 3.1 Method A: pip (Recommended)

```bash
# Install from PyPI (after publishing)
pip install deepclaw
```

### 3.2 Method B: GitHub (Latest)

```bash
# Clone repository
git clone https://github.com/opensourceclaw/deepclaw.git
cd deepclaw

# Install in development mode
pip install -e .

# Or install as package
pip install .
```

### 3.3 Verify Installation

```bash
# Check version
deepclaw --version

# Or
python -m deepclaw.cli.main --version

# Show help
deepclaw --help
```

## 4. Configuration

### 4.1 Default Config Location

```
~/.deepclaw/config.json
```

### 4.2 Custom Config

```bash
# Create custom config
deepclaw init my-project --config /path/to/config.json
```

### 4.3 Config Options

```json
{
  "research": {
    "default_depth": 3,
    "max_results": 10,
    "max_content": 5,
    "timeout": 30
  },
  "search": {
    "cache_enabled": true,
    "cache_ttl": 3600,
    "user_agent": "SciClaw/0.1.0"
  },
  "storage": {
    "data_dir": "~/.deepclaw/data",
    "cache_dir": "~/.deepclaw/cache"
  }
}
```

## 5. Usage

### 5.1 Basic Research

```bash
# Simple research
deepclaw research "AI ethics"

# With output file
deepclaw research "AI ethics" -o report.md

# With depth
deepclaw research "quantum computing" --depth 5 -o quantum.md

# Verbose output
deepclaw research "machine learning" -v
```

### 5.2 Search Only

```bash
# Search without full research
deepclaw search "deep learning" -o results.md
```

### 5.3 Initialize Project

```bash
# Create research project
deepclaw init my-project --topic "research topic"
```

## 6. Data Storage

### 6.1 Directory Structure

```
~/.deepclaw/
├── config.json          # User configuration
├── data/
│   └── research/        # Research reports (Markdown)
├── cache/
│   └── search_*.json    # Search result cache
└── logs/                # Application logs
```

### 6.2 Report Format

Reports are saved as Markdown files:

```markdown
# Research: {Topic}

**Date**: {YYYY-MM-DD}
**Duration**: {X minutes}

## Summary

{Brief summary}

## Key Findings

1. Finding 1
2. Finding 2
3. Finding 3

## Sources

1. [Source 1](url) - Title
2. [Source 2](url) - Title

---
*Generated by SciClaw v0.1.0*
```

## 7. Troubleshooting

### 7.1 Common Issues

| Issue | Solution |
|-------|----------|
| Command not found | Add Python bin to PATH |
| No search results | Check internet connection |
| Import errors | Reinstall: `pip install -e .` |
| Permission denied | Check directory permissions |

### 7.2 Debug Mode

```bash
# Enable verbose output
deepclaw research "topic" -v
```
