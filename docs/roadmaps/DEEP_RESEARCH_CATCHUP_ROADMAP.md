## 五、技术架构演进

### 当前架构
```
用户 → CLI/API → Agent Pipeline → Search → Report
```

### Phase 2 架构
```
用户 → CLI/API → Model Router → [o3/Claude/Gemini] → Search Pool → Report
                                    ↓
                              Memory Layer
```

### Phase 3 架构
```
用户 → CLI/API → Reasoning Engine → Dynamic Planner → Search Pool
                                    ↓
                              Multi-Modal Processor → Report
                                    ↓
                              Memory + Knowledge Graph
```
