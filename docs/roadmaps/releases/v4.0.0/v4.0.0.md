# SciClaw v4.0.0 Release Notes

**Version**: v4.0.0
**Date**: 2026-09-21
**Theme**: DeepClaw -> SciClaw identity integration milestone
**Plan**: `docs/plans/sciclaw-v4.0.0-plan.md`

---

## Release Summary

SciClaw v4.0.0 is the identity-integration milestone. The repository formerly
known as DeepClaw ships as **SciClaw — verifiable deep research for AI4S**: an
independent member of the agent family, sharing the ecosystem infrastructure
(claw-obs / claw-cog / claw-mem / claw-ctx) without depending on DevClaw.

In the same milestone the shared core package is merged back in, the
observability adapter is realigned with claw-obs v2.5.0, and the build/test
baseline is fully green. There are no functional changes to the research
pipeline in this release — it is a rename, a consolidation, and a baseline
hardening.

## Breaking change (identity only)

- **Package / binary**: `sciclaw` (the CLI was `deepclaw`). Plugin identity in
  `openclaw.plugin.json` is synced (it had been stale at 3.0.0).
- **Brand strings**: 147 files / 264 occurrences — README, SKILL, CONTRIBUTING,
  living docs, source comments and console prefixes — plus the three
  brand-bearing class names: `SciClawObserver`, `SciClawCogIntegration`,
  `SciClawLearningEngine`.
- **Flow class names stay**: `DeepResearchFlow` / `AutoResearchFlow` are stage
  semantics, not branding, and are unchanged.

## Runtime contracts: zero migration

Deliberately untouched in v4.0.0, so upgrading users migrate nothing. The
rename of these runtime identifiers is a separate task in the v4.0.x line, with
a compatibility read of the old location:

- `~/.deepclaw/*` data directories
- `DEEPCLAW_MEMORY_WORKSPACE`
- the `deepclaw` project-id default in the memory adapter
- the `"deepclaw"` claw-cog broadcast tag / sessionId prefix

## What changed

- **deepclaw-core merged into `src/core/`** (61 TS files) — single consumer, so
  the cross-repository `file:` dependency is gone and the library ships in-tree.
  `CORE_VERSION` stays `1.0.0`.
- **MetricsCollector ported** off the removed claw-obs v2.5.0 API; the now
  orphaned claw-obs `file:` dependency was dropped (zero imports).
- **dist and coverage snapshots rebuilt** after the merge (brand strings zeroed,
  core face included, stale artifacts dropped).

## Quality

- 900/900 tests passing across 71 test files (`npm test`).
- `tsc --noEmit` exit 0; `npm run build` exit 0.
- The tracked `dist/` snapshot is in sync: a full rebuild produces no tracked
  diff.

## Distribution

- **Private repository; no npm registry face** — v4.0.0 is not published to any
  registry and no dist-tags apply. Adoption is by clone (see README), or as an
  OpenClaw plugin through the platform-side installation path.
