## Proven capabilities (measured, not asserted)

- **Live pipeline**: multi-source search → claim extraction → per-claim verifier
  verdicts → four quality gates → report with an embedded evidence block. Gate
  failure withdraws the conclusion instead of shipping it (fail-closed).
- **Acceptance suite** (fixture mode, zero network) asserts source provenance,
  citation coverage, gate enforcement, verifier verdict presence and golden
  outputs; a live variant checks the same structural invariants against the
  network.
- **Benchmark** now consumes real orchestration output: 3/3 tasks, average
  overall **0.769** (`benchmark-results.json`).
- **Build smoke**: the `dist` entry point loads and `sciclaw --version` runs — a
  class of breakage that CI could not see before.
- **Test baseline at this tag**: 946 passed / 4 skipped (`npm test`), plus the
  26-case GA suite.

## Calibration limits (read this before quoting "verifiable")

- Two bias factors — **confirmation** and **temporal** — are not measurable from
  the inputs currently available and are therefore **excluded from gate
  verdicts**. They return when the corpus expansion lands in the v4.0.x line.
- The live acceptance variant checks structural invariants; it is not a
  benchmark of research quality.
- Verification backs the **evidence chain** — source provenance, citation
  coverage, gate enforcement, verifier verdicts. It does not certify the factual
  correctness of synthesized prose.

## Distribution

- The repository is **public** as of this milestone (`opensourceclaw/sciclaw`).
- **No npm publication** — SciClaw has no registry face; adopt by cloning the
  repository. (The `sciclaw` / `@sciclaw` npm namespace claim is tracked
  separately.)
- Reproduce locally: `npm ci && npm run build && npm run test:ga` (fixture, no
  network) and `npm run benchmark`.
