## 五、与现有 claw-xxx 项目的协同

```
Project Neo 智能体家族
    │
    ├── neoclaw (队长) - 任务编排
    ├── devclaw (工程师) - 代码开发
    ├── deepclaw (研究员) - Deep Research (v1-v3)
    ├── workclaw (工作协同) - 任务协调
    │
    └── 共享组件
            ├── claw-mem (记忆)
            ├── claw-ctx (上下文)
            ├── claw-obs (观测)
            ├── claw-eva (评估)
            ├── claw-gov (治理)
            └── claw-sec (安全)
```
