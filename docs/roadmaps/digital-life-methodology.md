## 方法论

### 自底向上 (探索期)

```
论文/基础组件 → 应用探索
     ↓
边做边找方向
```

**适用**: 早期探索，无明确目标

### 自顶向下 + 自底向上 (成熟期)

```
应用维度思考 → 向底层组件提需求 → 底层组件响应 → 碰撞创新
```

**适用**: 目标明确，追求工程化落地
