## 3. Module 2: Base Agent (`src/agents/base_agent.ts`)

### Exports

```typescript
export abstract class BaseAgent {
  readonly config: AgentConfig;

  constructor(config: AgentConfig);

  // ── Abstract (implemented by subclasses) ──
  abstract execute(task: AgentTask): Promise<AgentResult>;

  // ── Message queue ──
  sendMessage(msg: AgentMessage): void;
  receiveMessage(): AgentMessage | null;
  getMessageQueueSize(): number;

  // ── Status ──
  getStatus(): AgentStatusInfo;
  isBusy(): boolean;
}
```

### Internal State

```typescript
private messageQueue: AgentMessage[] = [];
private status: AgentStatus = AgentStatus.IDLE;
private currentTaskId: string | null = null;
private taskCount = 0;
```

### Key Behaviors

- **Message queue**: In-memory FIFO. `sendMessage` enqueues, `receiveMessage` dequeues (or returns null if empty).
- **Status transitions**: IDLE → BUSY (on `execute`) → COMPLETED (success) or ERROR (failure) → IDLE (reset)
- **Error handling in execute**: If `execute` throws, catch and return `AgentResult` with `status: "failed"` and error message in `errors[]`
- **Timeout**: Orchestrator is responsible for timeout enforcement (not the agent itself)

### Edge Cases

- Message queue overflow: Cap at 100 messages, drop oldest if exceeded
- Concurrent execute calls: Reject with error if already BUSY
- Empty message queue: `receiveMessage()` returns `null` (not throw)

## 4. Module 3: Orchestrator (`src/agents/orchestrator.ts`)

### Exports

```typescript
export class Orchestrator {
  constructor();

  // Agent management
  registerAgent(agent: BaseAgent): void;
  unregisterAgent(role: AgentRole): boolean;
  getAgent(role: AgentRole): BaseAgent | undefined;

  // Planning
  createPlan(topic: string, options?: {
    phases?: OrchestrationPhase[];
    timeoutMs?: number;
  }): OrchestrationPlan;

  // Execution
  executePlan(plan: OrchestrationPlan): Promise<OrchestrationResult>;

  // Communication
  sendMessage(msg: AgentMessage): void;
  broadcast(type: MessageType, payload: unknown): void;

  // Status
  getAgentStatuses(): Map<AgentRole, AgentStatusInfo>;
  isAnyAgentBusy(): boolean;
}
```

### Default Phase Sequence

```
Phase 1: Plan     [Planning]        depends on: none
  ↓ (output: research plan, queries)
Phase 2: Search   [Search]          depends on: [1]
  ↓ (output: sources, extracted content)
Phase 3: Synthesize [Synthesis]     depends on: [2]
  ↓ (output: knowledge graph, validated claims)
Phase 4: Write    [Writing]         depends on: [3]
  ↓ (output: final report)
```

### Execution Algorithm (`executePlan`)

```
1. Validate plan: all agents registered, phase dependencies exist
2. For each phase (in order):
   a. Check all dependency phases completed successfully
   b. Dispatch tasks to all agents in phase.agents (parallel if multiple)
   c. Wait for all agents in phase to complete (or timeout)
   d. Collect results, compute phase duration
   e. If any agent failed: decide fail-fast vs continue based on phase config
3. Aggregate results: combine outputs from all phases
4. Return OrchestrationResult
```

### Task Dispatch Algorithm

For each agent in a phase:

```typescript
async function dispatchTask(agent: BaseAgent, task: AgentTask): Promise<AgentResult> {
  let lastError: Error | undefined;
  for (let attempt = 0; attempt <= agent.config.maxRetries; attempt++) {
    try {
      const result = await Promise.race([
        agent.execute(task),
        timeout(agent.config.timeoutMs),
      ]);
      return result;
    } catch (err) {
      lastError = err as Error;
      if (attempt < agent.config.maxRetries) {
        await sleep(1000 * (attempt + 1)); // exponential backoff
      }
    }
  }
  return {
    taskId: task.id,
    role: agent.config.role,
    status: "failed",
    output: null,
    artifacts: [],
    metrics: { durationMs: 0 },
    errors: [lastError?.message ?? "Unknown error"],
  };
}
```

### Aggregation Logic

After all phases complete:

```typescript
function aggregateResults(phases: PhaseResult[]): unknown {
  const outputs: Record<string, unknown> = {};
  for (const phase of phases) {
    for (const result of phase.results) {
      if (result.status !== "failed" && result.output) {
        outputs[result.role] = result.output;
      }
    }
  }
  return outputs;
}
```

### Error Handling

- **Missing agent**: `registerAgent` not called for a role in plan → throw `Error` with message listing missing agents
- **Phase timeout**: Agent exceeds `timeoutMs` → mark as failed with "Agent timeout" error
- **All retries exhausted**: Final result has `status: "failed"` with accumulated error messages
- **Partial failure in phase**: If one agent fails but others succeed → phase status = "partial" (not "failed")
- **Dependency failure**: If a dependency phase has status "failed", subsequent phases still execute (graceful degradation) but the final status reflects the failure

### Edge Cases

- Empty plan (no phases) → return result with `overallStatus: "success"`, empty phases array
- Single-agent plan → works like a single-agent execution
- Concurrent `executePlan` calls → serialize via internal queue (reject if already executing)
- Agent throws on `execute` → caught by retry logic, never propagates

- Empty topic → return failed result with "Empty topic" error
- NER module failure → fall back to simple keyword splitting (split by commas, "and", "vs")
- No subtopics generated → use topic itself as the only query

```typescript

  capabilities: ["knowledge_graph", "claim_validation", "cross_referencing"],
  maxRetries: 2,
```

### Execution Algorithm

```
Input:  {
  sources: SourceInfo[];
  extractedContent: ExtractedContent[];
  topic: string;
}
Output: {
  knowledgeGraph: KnowledgeGraph;
  validatedClaims: VerificationResult[];
  riskAssessments: RiskAssessment[];
  crossReferences: Array<{
    sourceA: string;
    sourceB: string;
    agreement: number;
    contradictions: string[];
  }>;
  contradictions: Array<{
    claim: Claim;
    contradictingSources: string[];
    severity: "low" | "medium" | "high";
  }>;
}
```

1. **Build knowledge graph**: Use `buildGraph()` from `src/knowledge/graph_builder.ts`
   - Collect all entities from extracted content
   - Build relations based on co-occurrence analysis
2. **Validate claims**: Use `FactCheckService` from `src/validation/factcheck_service.ts`
   - Cross-reference each claim against all source texts
   - Batch verify via `verifyClaims()`
3. **Assess risk**: Use `RiskScorer` from `src/validation/risk_scorer.ts`
   - For each claim, compute risk based on source score, claim type, verification
4. **Cross-reference sources**: Compare claims across sources to find agreements and contradictions
   - Agreement: both sources have supporting evidence for same claim
   - Contradiction: one source supports, another contradicts
5. **Identify contradictions**: Flag claims with conflicting evidence across sources

### Cross-Reference Algorithm

```typescript
function crossReference(sources: SourceInfo[], claims: Map<string, Claim[]>): CrossReference[] {
  const refs: CrossReference[] = [];
  const claimTexts = [...claims.values()].flat();

  for (let i = 0; i < sources.length; i++) {
    for (let j = i + 1; j < sources.length; j++) {
      const agreement = computeAgreement(claims.get(sources[i].url) ?? [], claims.get(sources[j].url) ?? []);
      const contradictions = findContradictions(claims.get(sources[i].url) ?? [], claims.get(sources[j].url) ?? []);
      if (agreement > 0 || contradictions.length > 0) {
        refs.push({
          sourceA: sources[i].url,
          sourceB: sources[j].url,
          agreement,
          contradictions,
        });
      }
    }
  }
  return refs;
}
```

### Error Handling

- Empty sources → return empty graph, empty arrays, status "partial"
- Knowledge graph builder failure → skip graph, continue with validation
- FactCheckService failure → mark all claims as PENDING
- No contradictions found → empty contradictions array (not an error)

## 10. Module 9: Benchmark Metrics (`src/benchmark/metrics.ts`)

### Exports

```typescript
export function computeFactuality(
  result: { claims: string[]; verified: VerificationResult[] },
  expectedFacts: string[]
): number;

export function computeCompleteness(
  result: { sources: string[]; sections: string[] },
  expectedSources: string[],
  minSections: number
): number;

export function computeCitationQuality(
  result: { citations: Citation[] }
): number;

export function computeReasoningDepth(
  result: { knowledgeGraph: KnowledgeGraph; crossReferences: CrossReference[] }
): number;

export function computeOverall(scores: BenchmarkScore, weights: {
  factuality: number;
  completeness: number;
  citation: number;
  reasoning: number;
}): number;
```

### Algorithm Details

**`computeFactuality`**:
```
1. For each expected fact, check if it appears in any verified claim
2. Use text overlap (word intersection / max length) ≥ 0.5 as match threshold
3. factuality_score = matching_facts / total_expected_facts
4. Apply verification bonus: verified claims count double
```

```typescript
function computeFactuality(result, expectedFacts): number {
  if (expectedFacts.length === 0) return 1.0;
  const verifiedTexts = result.verified
    .filter(v => v.status === VerificationStatus.VERIFIED)
    .map(v => v.claim.text.toLowerCase());

  let matches = 0;
  for (const fact of expectedFacts) {
    const factLower = fact.toLowerCase();
    if (verifiedTexts.some(t => t.includes(factLower) || overlapRatio(t, factLower) >= 0.5)) {
      matches++;
    }
  }
  return matches / expectedFacts.length;
}
```

**`computeCompleteness`**:
```
1. Source coverage: matching_sources / expected_sources
2. Section coverage: actual_sections / min_sections (capped at 1.0)
3. completeness = source_coverage × 0.6 + section_coverage × 0.4
```

**`computeCitationQuality`**:
```
1. All citations have sourceId (length 8 hex) → +0.2
2. All citations have valid URL → +0.2
3. All citations have qualityScore ≥ 0.5 → +0.2
4. At least 3 citations → +0.2
5. Citations from ≥ 2 domains → +0.2
Total: 0.0 - 1.0
```

**`computeReasoningDepth`**:
```
1. If knowledge graph exists:
   - Find longest path in graph (BFS from each node)
   - reasoning = min(longest_path_length / 3, 1.0)
2. If cross-references exist:
   - Cross-reference count bonus: min(refs / 5, 1.0) × 0.3
3. If neither exists: 0.0
```

**`computeOverall`**:
```typescript
function computeOverall(scores, weights): number {
  return (
    scores.factuality * weights.factuality +
    scores.completeness * weights.completeness +
    scores.citation * weights.citation +
    scores.reasoning * weights.reasoning
  );
}
```

### Error Handling

- Empty expected facts → factuality = 1.0 (trivially passing)
- No sources → completeness = 0.0
- No citations → citation = 0.0
- No knowledge graph → reasoning = 0.0
- All scores 0.0 if no meaningful data

```typescript
}
```

### Execution Algorithm (`runTask`)

```
1. Look up task by taskId
2. Create orchestrator with 4 agents
3. Create execution plan from task input
4. Execute plan via orchestrator
5. Compute scores using metrics module
6. Return BenchmarkResult with:
   - Scores from metrics
   - Pass/fail based on threshold
   - Duration, token count, source count, claim count
```

### `runAll` Execution

```
1. For each registered task:
   a. runTask(taskId)
   b. Collect result
2. Aggregate into BenchmarkReport:
   - Compute average scores
   - Compute category breakdowns
   - Compute pass rate
3. Return report
```

### Error Handling

- Task not found → throw `Error("Task not found: ${taskId}")`
- Orchestrator failure → return failed result with error, continue to next task
- Timeout per task → configurable (default 120000ms), mark as failed
- Empty task registry → return report with 0 tasks, 0 pass rate
- Partial category match → only run registered tasks in category

### Report Generation Algorithm

```typescript
function generateReport(results, version): BenchmarkReport {
  const totalTasks = results.length;
  const passedTasks = results.filter(r => r.passed).length;
  const passRate = totalTasks > 0 ? passedTasks / totalTasks : 0;

  const avgScores = {
    factuality: average(results.map(r => r.scores.factuality)),
    completeness: average(results.map(r => r.scores.completeness)),
    citation: average(results.map(r => r.scores.citation)),
    reasoning: average(results.map(r => r.scores.reasoning)),
    overall: average(results.map(r => r.scores.overall)),
  };

  const categories: BenchmarkCategory[] = ["factuality", "completeness", "citation", "reasoning", "multi_agent"];
  const categoryBreakdown = {} as BenchmarkReport["categoryBreakdown"];
  for (const cat of categories) {
    const catResults = results.filter(r => r.category === cat);
    categoryBreakdown[cat] = {
      count: catResults.length,
      passed: catResults.filter(r => r.passed).length,
      avgScore: catResults.length > 0 ? average(catResults.map(r => r.scores.overall)) : 0,
    };
  }

  return {
    timestamp: new Date(),
    version,
    totalTasks,
    passedTasks,
    passRate: Math.round(passRate * 1000) / 1000,
    averageScores: avgScores,
    categoryBreakdown,
    results,
  };
}
```

### Comparison Report

```typescript
function compareReports(baseline, current): ComparisonReport {
  return {
    baseline,
    current,
    delta: {
      passRate: current.passRate - baseline.passRate,
      avgScore: current.averageScores.overall - baseline.averageScores.overall,
      regressionTasks: current.results
        .filter(cr => {
          const br = baseline.results.find(r => r.taskId === cr.taskId);
          return br && cr.scores.overall < br.scores.overall - 0.05;
        })
        .map(r => r.taskName),
      improvedTasks: current.results
        .filter(cr => {
          const br = baseline.results.find(r => r.taskId === cr.taskId);
          return br && cr.scores.overall > br.scores.overall + 0.05;
        })
        .map(r => r.taskName),
    },
  };
}
```

### Error Handling

- Empty results → report with 0 tasks, 0% pass rate
- Single category → breakdown shows only that category
- Missing baseline tasks in comparison → treated as new (not regression)
- Very long task names → truncated to 50 chars in markdown table
