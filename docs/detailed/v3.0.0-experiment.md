### Edge Cases

- `maxSteps` clamped to `[3, 100]`
- `maxVariables` clamped to `[2, 50]`
- `defaultTimeoutMs` clamped to `[1000, 300000]` (1s–5min)
- `minConfidenceForSupport` clamped to `[0.3, 0.9]`
- Step with circular dependencies → rejected by designer validation
- Duplicate variable names → suffixed with index

### Core Algorithm: `design`

```
Input:  Hypothesis (from hypothesis module)
Output: Experiment

1. Determine experiment type from hypothesis category:
   - causal → CONTROLLED
   - correlational → OBSERVATIONAL
   - explanatory → COMPARATIVE
   - predictive → SIMULATION
   - comparative → A_B_TEST

2. Extract variables from hypothesis statement:
   - Independent variables: the "cause" / manipulated factor
   - Dependent variables: the "effect" / measured outcome
   - Control variables: identified confounders
   - For each variable, estimate expected range

3. Generate experiment steps:
   a. SETUP step: define variables, prepare environment
   b. BASELINE step: measure initial state
   c. MANIPULATION step(s): apply independent variable changes
   d. MEASUREMENT step(s): record dependent variable responses
   e. ANALYSIS step: compare results against baseline
   f. VALIDATION step: check constraints, verify reproducibility
   g. CONCLUSION step: summarize findings

4. Define metrics based on hypothesis type:
   - causal → precision, recall of cause-effect relationship
   - correlational → correlation coefficient accuracy
   - predictive → prediction accuracy, F1 score
   - comparative → relative improvement percentage

5. Set constraints:
   - Time constraint: defaultTimeoutMs
   - Resource constraint: maxVariables, maxSteps

6. Validate experiment structure
7. Return Experiment with status DRAFT
```

### Step Generation

```typescript
function generateSteps(hypothesis: {
  statement: string;
  category: string;
}): ExperimentStep[] {
  const steps: ExperimentStep[] = [];

  // Step 1: Setup
  steps.push({
    id: crypto.randomUUID(),
    order: 1,
    action: "setup",
    description: "Define experimental variables and prepare test environment",
    expectedOutcome: "Variables identified and environment ready",
    durationEstimateMs: 1000,
    dependencies: [],
  });

  // Step 2: Baseline measurement
  steps.push({
    id: crypto.randomUUID(),
    order: 2,
    action: "measure_baseline",
    description: `Measure baseline state for hypothesis: ${hypothesis.statement}`,
    expectedOutcome: "Baseline metrics recorded",
    durationEstimateMs: 2000,
    dependencies: [steps[0]!.id],
  });

  // Step 3-5: Manipulation rounds (3 rounds for robustness)
  for (let round = 1; round <= 3; round++) {
    steps.push({
      id: crypto.randomUUID(),
      order: 2 + round,
      action: `manipulation_round_${round}`,
      description: `Apply independent variable change (round ${round}/3)`,
      expectedOutcome: "Variable manipulated, system responded",
      durationEstimateMs: 3000,
      dependencies: [steps[1 + round - 1]!.id],
    });
  }

  // Step 6: Analysis
  steps.push({
    id: crypto.randomUUID(),
    order: 6,
    action: "analyze",
    description: "Analyze results across all manipulation rounds",
    expectedOutcome: "Statistical significance determined",
    durationEstimateMs: 2000,
    dependencies: [steps[4]!.id], // depends on last manipulation round
  });

  // Step 7: Validation
  steps.push({
    id: crypto.randomUUID(),
    order: 7,
    action: "validate",
    description: "Validate results against constraints and reproducibility",
    expectedOutcome: "Results validated and reproducible",
    durationEstimateMs: 2000,
    dependencies: [steps[5]!.id],
  });

  return steps;
}
```

### Variable Extraction

```typescript
function extractVariables(statement: string): ExperimentVariable[] {
  const variables: ExperimentVariable[] = [];

  // Pattern: "X causes/affects/influences Y"
  const causalMatch = statement.match(
    /^(.+?)\s+(causes?|affects?|influences?|leads?\s+to|impacts?)\s+(.+)$/i,
  );
  if (causalMatch) {
    variables.push({
      id: crypto.randomUUID(),
      name: causalMatch[1]!.trim(),
      type: VariableType.INDEPENDENT,
      description: `Independent variable: ${causalMatch[1]!.trim()}`,
    });
    variables.push({
      id: crypto.randomUUID(),
      name: causalMatch[3]!.trim(),
      type: VariableType.DEPENDENT,
      description: `Dependent variable: ${causalMatch[3]!.trim()}`,
    });
    return variables;
  }

  // Pattern: "X is associated/correlated with Y"
  const corrMatch = statement.match(
    /^(.+?)\s+(is\s+)?(associated|correlated|linked|related)\s+(with|to)\s+(.+)$/i,
  );
  if (corrMatch) {
    variables.push({
      id: crypto.randomUUID(),
      name: corrMatch[1]!.trim(),
      type: VariableType.INDEPENDENT,
      description: `Variable A: ${corrMatch[1]!.trim()}`,
    });
    variables.push({
      id: crypto.randomUUID(),
      name: corrMatch[5]!.trim(),
      type: VariableType.DEPENDENT,
      description: `Variable B: ${corrMatch[5]!.trim()}`,
    });
    return variables;
  }

  // Fallback: extract noun phrases as potential variables
  const nounPhrases = statement.match(/\b([A-Z][a-z]+(?:\s+[A-Z][a-z]+)*)\b/g);
  if (nounPhrases) {
    for (const phrase of nounPhrases.slice(0, 5)) {
      variables.push({
        id: crypto.randomUUID(),
        name: phrase,
        type: VariableType.INDEPENDENT,
        description: `Extracted variable: ${phrase}`,
      });
    }
  }

  return variables;
}
```

### Experiment Validation

```typescript
function validateExperiment(experiment: Experiment): {
  valid: boolean;
  errors: string[];
} {
  const errors: string[] = [];

  if (experiment.steps.length < 3) {
    errors.push("Experiment must have at least 3 steps");
  }
  if (experiment.steps.length > DEFAULT_EXPERIMENT_CONFIG.maxSteps) {
    errors.push(`Experiment exceeds max steps (${DEFAULT_EXPERIMENT_CONFIG.maxSteps})`);
  }
  if (experiment.variables.length < 2) {
    errors.push("Experiment must have at least 2 variables");
  }
  if (!experiment.variables.some(v => v.type === VariableType.INDEPENDENT)) {
    errors.push("Experiment must have at least one independent variable");
  }
  if (!experiment.variables.some(v => v.type === VariableType.DEPENDENT)) {
    errors.push("Experiment must have at least one dependent variable");
  }
  if (hasCycleInSteps(experiment.steps)) {
    errors.push("Experiment steps contain circular dependencies");
  }
  if (experiment.metrics.length === 0) {
    errors.push("Experiment must have at least one metric");
  }

  return { valid: errors.length === 0, errors };
}
```

### Error Handling

- Empty hypothesis statement → throw `Error("Hypothesis statement is required")`
- Null hypothesis → throw `TypeError("Hypothesis cannot be null")`
- Statement with no extractable variables → create generic variables "Factor_A" and "Factor_B"
- designBatch with empty array → return empty array

### Edge Cases

- Very complex hypothesis (> 5 variables) → cap at maxVariables, warn about truncation
- Hypothesis with only one noun phrase → create a second variable from the statement's domain
- All variables classified as INDEPENDENT → reclassify the last one as DEPENDENT

### Core Algorithm: `run`

```
Input:  Experiment
Output: ExperimentResult (duration < 30s per acceptance criteria)

1. Validate experiment is in READY state
2. Set experiment status to RUNNING, record startedAt
3. Initialize result accumulator:
   - stepResults: []
   - metricResults: []
   - observations: []
4. Sort steps by order
5. For each step (in dependency-respecting order):
   a. Check all dependencies completed with status "passed"
      - If any dependency failed → skip this step (status: "skipped")
   b. Record step start time
   c. Execute step with timeout (defaultTimeoutMs per step):
      - SETUP → initialize variables, no-op in unit test context
      - BASELINE → record initial metric values
      - MANIPULATION → modify independent variables, observe response
      - MEASUREMENT → record metric values after manipulation
      - ANALYSIS → compute statistical measures
      - VALIDATION → check constraints
   d. Record step end time, duration
   e. Push StepResult
6. Measure all metrics against final variable state
7. Record total duration
8. Set experiment status to COMPLETED
9. Return ExperimentResult
```

### Step Execution

```typescript
async function executeStep(
  step: ExperimentStep,
  variables: ExperimentVariable[],
): Promise<StepResult> {
  const startTime = Date.now();

  try {
    let actualOutcome = "";

    switch (step.action) {
      case "setup":
        actualOutcome = `Setup complete: ${variables.length} variables configured`;
        break;
      case "measure_baseline":
        actualOutcome = `Baseline measured: ${variables.map(v => `${v.name}=${v.currentValue ?? "N/A"}`).join(", ")}`;
        break;
      case "analyze":
        actualOutcome = "Analysis complete: statistical measures computed";
        break;
      case "validate":
        actualOutcome = "Validation complete: all constraints checked";
        break;
      default:
        // manipulation or measurement rounds
        actualOutcome = `${step.action} completed successfully`;
        break;
    }

    return {
      stepId: step.id,
      order: step.order,
      status: "passed",
      actualOutcome,
      durationMs: Date.now() - startTime,
      errors: [],
    };
  } catch (err) {
    return {
      stepId: step.id,
      order: step.order,
      status: "failed",
      actualOutcome: "",
      durationMs: Date.now() - startTime,
      errors: [err instanceof Error ? err.message : "Unknown error"],
    };
  }
}
```

### Metric Measurement

```typescript
function measureMetric(
  metric: ExperimentMetric,
  variables: ExperimentVariable[],
  stepResults: StepResult[],
): MetricResult {
  // In unit test context, compute deterministic values
  const passedSteps = stepResults.filter(s => s.status === "passed").length;
  const totalSteps = stepResults.length;

  let actualValue: number;

  switch (metric.type) {
    case MetricType.ACCURACY:
      actualValue = totalSteps > 0 ? passedSteps / totalSteps : 0;
      break;
    case MetricType.LATENCY:
      actualValue = stepResults.reduce((sum, s) => sum + s.durationMs, 0);
      break;
    case MetricType.THROUGHPUT:
      actualValue = totalSteps > 0
        ? passedSteps / (stepResults.reduce((sum, s) => sum + s.durationMs, 0) / 1000)
        : 0;
      break;
    default:
      actualValue = totalSteps > 0 ? passedSteps / totalSteps : 0;
  }

  const deviation = metric.targetValue !== 0
    ? Math.abs(actualValue - metric.targetValue) / Math.abs(metric.targetValue)
    : Math.abs(actualValue - metric.targetValue);

  return {
    metricId: metric.id,
    name: metric.name,
    type: metric.type,
    targetValue: metric.targetValue,
    actualValue,
    deviation,
    passed: deviation <= metric.tolerance,
  };
}
```

### Performance Target

Acceptance criteria: experiment run time < 30s. Each step has a built-in timeout, and the total time is:
- 7 steps × max 3s per step = 21s theoretical max
- Plus measurement overhead: ~5s
- Total: < 30s guaranteed

### Error Handling

- Experiment already RUNNING → throw `Error("Experiment is already running")`
- Experiment status is FAILED/CANCELLED → throw `Error("Cannot run experiment in ${status} state")`
- Step execution throws → catch, mark step as failed, continue with remaining steps
- All steps fail → overall status "failed", metricResults computed from available data
- Timeout per step → use `Promise.race` with step timeout

### Edge Cases

- Empty steps array → return result immediately with status "failed"
- Single step experiment → run that step, compute metrics from single result
- cancel() during execution → set status to CANCELLED, current step marked as failed
- Concurrent run() calls on same experiment → rejected (already running check)

### Core Algorithm: `evaluate`

```
Input:  ExperimentResult, optional Hypothesis
Output: EvaluationReport

1. Compute metric summary:
   - Count passed/failed metrics
   - Compute pass rate = passed / total

2. Compute step summary:
   - Count passed/failed/skipped steps
   - Compute completion rate = passed / total

3. Compute overall score:
   - Metric pass rate × 0.4
   - Step completion rate × 0.3
   - Average metric deviation (inverse) × 0.2
   - Observation count (capped) × 0.1

4. Determine hypothesis support:
   - overallScore ≥ minConfidenceForSupport → supported
   - Otherwise → not supported
   - If hypothesis.confidence from input is high but score is low → flag as "needs review"

5. Extract findings:
   - Significant: metric deviations < 0.1, all steps passed
   - Medium: most metrics passed, minor step failures
   - Low: marginal results

6. Generate recommendations:
   - If metric pass rate < 0.5 → "Increase sample size"
   - If step failures > 0 → "Review failed steps for design flaws"
   - If overallScore > 0.8 → "Results are conclusive, consider publication"
   - If overallScore < 0.4 → "Redesign experiment with tighter controls"

7. Return EvaluationReport
```

### Overall Score Computation

```typescript
function computeOverallScore(result: ExperimentResult): number {
  const { metricResults, stepResults, observations } = result;

  // Metric pass rate (weight: 0.4)
  const metricPassRate = metricResults.length > 0
    ? metricResults.filter(m => m.passed).length / metricResults.length
    : 0;

  // Step completion rate (weight: 0.3)
  const stepCompletionRate = stepResults.length > 0
    ? stepResults.filter(s => s.status === "passed").length / stepResults.length
    : 0;

  // Average metric deviation inverse (weight: 0.2)
  const avgDeviation = metricResults.length > 0
    ? metricResults.reduce((sum, m) => sum + m.deviation, 0) / metricResults.length
    : 1.0;
  const deviationScore = Math.max(0, 1.0 - avgDeviation);

  // Observation richness (weight: 0.1)
  const observationScore = Math.min(observations.length / 5, 1.0);

  return (
    metricPassRate * 0.4 +
    stepCompletionRate * 0.3 +
    deviationScore * 0.2 +
    observationScore * 0.1
  );
}
```

### Finding Extraction

```typescript
function extractFindings(result: ExperimentResult): Finding[] {
  const findings: Finding[] = [];

  // Finding: all metrics passed
  const allMetricsPassed = result.metricResults.every(m => m.passed);
  if (allMetricsPassed && result.metricResults.length > 0) {
    findings.push({
      id: crypto.randomUUID(),
      description: "All experimental metrics met their target values",
      significance: "high",
      supportingMetrics: result.metricResults.map(m => m.metricId),
      relatedSteps: [],
    });
  }

  // Finding: specific metric significantly exceeded target
  for (const metric of result.metricResults) {
    if (metric.deviation < 0.05 && metric.passed) {
      findings.push({
        id: crypto.randomUUID(),
        description: `Metric "${metric.name}" significantly exceeded target (deviation: ${(metric.deviation * 100).toFixed(1)}%)`,
        significance: "medium",
        supportingMetrics: [metric.metricId],
        relatedSteps: [],
      });
    }
  }

  // Finding: step failures
  const failedSteps = result.stepResults.filter(s => s.status === "failed");
  if (failedSteps.length > 0) {
    findings.push({
      id: crypto.randomUUID(),
      description: `${failedSteps.length} experiment step(s) failed: ${failedSteps.map(s => s.stepId).join(", ")}`,
      significance: failedSteps.length > 1 ? "high" : "medium",
      supportingMetrics: [],
      relatedSteps: failedSteps.map(s => s.stepId),
    });
  }

  return findings;
}
```

### Error Handling

- Empty result (no steps, no metrics) → overallScore = 0, empty findings
- Result with status "failed" → still evaluate, flag as "experiment failed" finding
- Null hypothesis → skip hypothesis support check, focus on metrics only
- Negative metric values → use absolute value for deviation calculation

### Edge Cases

- All metrics at exactly target (deviation = 0) → pass, deviationScore = 1.0
- Very large deviation (> 10x target) → deviationScore = 0
- Zero step results → stepCompletionRate = 0, overall score dominated by metrics
- Conflicting findings (some high, some low) → report all, let user interpret

```
1. experiment = designer.design(hypothesis)
```
