## 1. 现状分析

### 1.1 LLM 现状

| 项目 | 详情 |
|------|------|
| 文件 | `src/llm/index.ts` (单一文件, ~33 LOC) |
| 模式 | Provider 注册表 + Map 查找 |
| 接口 | `LLMProvider.complete(prompt, options)` |
| 实现 | **无** — 零个实际 provider 注册 |
| synthesize | 硬编码 markdown 拼接（非 LLM） |
| 模型指定 | 将 `model` 参数误用为 provider 名称 |

**结论**: 现有 LLM 模块是占位符，零实际功能。应直接替换为 OpenClaw 适配器。

### 1.2 OpenClaw Gateway 能力

| 能力 | 详情 |
|------|------|
| 传输 | WebSocket (port 18789) + HTTP REST |
| 协议 | JSON-RPC / OpenAI-compatible |
| 模型 | 64+ providers: OpenAI, Anthropic, Google, DeepSeek, xAI, Groq... |
| 推理支持 | o3/opus reasoning |
| 成本 | 每个模型内置 USD/1M tokens 定价 |
| Fallback | Gateway 自带 fallback chain |
| 认证 | API key / OAuth / trusted-proxy |

### 1.3 搜索现状

| 项目 | v3.0.3 当前 | v3.2.0 目标 |
|------|------------|------------|
| 源数量 | 3（内置）+ 可注册 | 100+ |
| 去重 | URL 规范化 | URL + 语义相似度 |
| 质量过滤 | 无 | 信任站点白名单 |
| 内容提取 | snippet only | 全文爬取 |
| LLM 增强 | 无 | 排序 + 扩展 + 摘要 |

## 3. Phase A: OpenClaw Model Integration

### 3.1 ModelAdapter

#### 类型定义

```typescript
// src/model/types.ts

export type ModelProvider = "openai" | "anthropic" | "google" | "deepseek"
  | "xai" | "groq" | "mistral" | "ollama" | string;

export type TaskCategory = "reasoning" | "analysis" | "coding"
  | "summarization" | "embedding" | "creative" | "default";

export interface ModelRequest {
  messages: Array<{ role: "system" | "user" | "assistant"; content: string }>;
  task?: TaskCategory;
  options?: {
    temperature?: number;
    maxTokens?: number;
    reasoningEffort?: "low" | "medium" | "high";
    streaming?: boolean;
  };
}

export interface ModelResponse {
  content: string;
  model: string;             // 实际使用的模型 ID
  provider: ModelProvider;
  usage?: {
    inputTokens: number;
    outputTokens: number;
    costUSD: number;
  };
  latencyMs: number;
}

export interface ModelAdapterConfig {
  baseUrl: string;           // OpenClaw Gateway URL，默认 http://127.0.0.1:18789
  apiKey?: string;           // Gateway 认证令牌
  timeoutMs: number;         // 默认 60000
  defaultModel: string;      // 默认 "anthropic/claude-sonnet-4-6"
}
```

#### 接口

```typescript
// src/model/adapter.ts

export class OpenClawModelAdapter {
  constructor(config?: Partial<ModelAdapterConfig>);

  /** Send a chat completion request via OpenClaw Gateway. */
  async chat(request: ModelRequest): Promise<ModelResponse>;

  /** Stream chat completion. */
  async chatStream(
    request: ModelRequest,
    onToken: (token: string) => void,
  ): Promise<ModelResponse>;

  /** Health check — whether gateway is reachable. */
  async healthCheck(): Promise<boolean>;

  /** List available models from gateway. */
  async listModels(): Promise<string[]>;
}
```

#### 通信协议

使用 OpenClaw Gateway 的 HTTP REST 接口（OpenAI 兼容）：

```
POST http://127.0.0.1:18789/v1/chat/completions
Authorization: Bearer {apiKey}
Content-Type: application/json

{
  "model": "anthropic/claude-sonnet-4-6",
  "messages": [...],
  "temperature": 0.7,
  "max_tokens": 4096
}
```

无需 SDK — 复用现有 `ConnectionPool.fetch()` 发起 HTTP 请求。与 WebSocket 协议相比，HTTP REST 更简单、更利于测试和调试。

### 3.2 ModelRouter

```typescript
// src/model/router.ts

export class ModelRouter {
  constructor(
    private adapter: OpenClawModelAdapter,
    private config?: Partial<RouterConfig>,
  );

  /** Route a request to the optimal model based on task type. */
  async route(request: ModelRequest): Promise<ModelResponse>;

  /** Get the recommended model for a task type. */
  getRecommendedModel(task: TaskCategory): string;
}

// 路由规则
const TASK_MODEL_MAP: Record<TaskCategory, string> = {
  reasoning:     "openai/o3-mini",               // o3 reasoning
  analysis:      "anthropic/claude-opus-4-6",    // 深度分析
  coding:        "anthropic/claude-sonnet-4-6",  // 代码生成
  summarization: "google/gemini-3-flash-preview", // 快速摘要
  embedding:     "openai/gpt-4o",               // 嵌入
  creative:      "anthropic/claude-opus-4-6",   // 创意写作
  default:       "anthropic/claude-sonnet-4-6",
};
```

**路由逻辑**:
1. 检查 `request.task`，匹配 TASK_MODEL_MAP
2. 检查成本预算 — 高成本任务降级到更经济的模型
3. 委托给 `ModelAdapter.chat()`，自动携带 fallback 逻辑

### 3.3 API Fallback

```typescript
// src/model/fallback.ts

export interface FallbackEntry {
  primary: string;
  fallbacks: string[];  // 按优先级排列的备选模型
}

const DEFAULT_FALLBACKS: FallbackEntry[] = [
  { primary: "anthropic/claude-opus-4-6", fallbacks: ["openai/gpt-5.5", "google/gemini-3-flash-preview"] },
  { primary: "anthropic/claude-sonnet-4-6", fallbacks: ["google/gemini-3-flash-preview", "deepseek/deepseek-v4-flash"] },
  { primary: "openai/gpt-5.5", fallbacks: ["anthropic/claude-sonnet-4-6", "google/gemini-3-pro-preview"] },
];

export class FallbackHandler {
  constructor(
    private adapter: OpenClawModelAdapter,
    private fallbacks: FallbackEntry[] = DEFAULT_FALLBACKS,
  );

  /**
   * Execute with automatic fallback.
   * If primary model fails (network error / timeout / rate limit),
   * try each fallback in order until one succeeds.
   */
  async execute(
    request: ModelRequest,
    model: string,
  ): Promise<ModelResponse>;
}
```

OpenClaw Gateway 自身也支持 fallback chain，但客户端侧增加一层额外保障（处理 Gateway 不可用场景）。

### 4.2 Smart Deduplication

```typescript
// src/search/dedup.ts

export class SmartDeduplicator {
  /** Simple fast dedup by URL + title normalization. */
  static fastDedup(results: SearchResult[]): SearchResult[];

  /**
   * Semantic dedup: group similar results using Jaccard similarity on
   * tokenized title+snippet, keep the highest-weight one per group.
   */
  static semanticDedup(
    results: SearchResult[],
    threshold?: number,  // Jaccard threshold, default 0.8
  ): SearchResult[];

  /**
   * Two-phase dedup: fast URL dedup → semantic dedup on near-dupes.
   */
  static hybridDedup(results: SearchResult[]): SearchResult[];
}
```

采用 Jaccard 相似度（不依赖 LLM），零额外延迟。0.8 阈值平衡去重率和召回率。

## 5. Phase C: Model-Enhanced Search

```typescript
// src/search/llm-rank.ts

export class LLMSearchEnhancer {
  constructor(private adapter: OpenClawModelAdapter);

  /**
   * Use LLM to rank search results by relevance to query.
   * Batch: send top-N results as context, ask LLM to re-rank.
   */
  async rankResults(
    query: string,
    results: SearchResult[],
    topN?: number,
  ): Promise<SearchResult[]>;

  /**
   * Use LLM to expand query for better recall.
   * Generate 3-5 alternative queries covering synonyms + related concepts.
   */
  async expandQuery(query: string): Promise<string[]>;

  /**
   * Use LLM to generate a concise summary of search results.
   * 3-5 sentence summary with key findings.
   */
  async summarizeResults(
    query: string,
    results: SearchResult[],
  ): Promise<string>;

  /**
   * Batch rank + expand + summarize in a single LLM call for efficiency.
   */
  async enhance(
    query: string,
    results: SearchResult[],
  ): Promise<{
    ranked: SearchResult[];
    expandedQueries: string[];
    summary: string;
  }>;
}
```

**Prompt 设计**（单次 LLM 调用完成三项任务）:
```
System: You are a search quality evaluator. Given a query and results:
1. Re-rank results by relevance (1-5 scale)
2. Suggest 3 expanded queries
3. Write a 3-sentence summary

Respond in JSON: {"ranked": [...], "expandedQueries": [...], "summary": "..."}
```

## 6. 集成与数据流

### 6.1 请求流

```
User: deepResearch("topic")
  │
  ▼
search() ← cache check (v3.0.2)
  │
  ▼
SearchCoordinator.search() (v3.0.3)
  ├─ 100+ sources concurrent
  ├─ DeepCrawler.crawlMany() ← 全文提取
  ├─ SmartDeduplicator.hybridDedup()
  └─ TrustFilter.filter()
  │
  ▼
LLMSearchEnhancer.enhance() ← OpenClaw Gateway
  ├─ ModelRouter.route(task="analysis") → claude-opus-4-6
  ├─ expandQuery → 3 alternative queries → re-search
  ├─ rankResults → re-ranked by relevance
  └─ summarizeResults → 3-sentence summary
  │
  ▼
AggregatedResults + summary + expanded queries
```

## 7. 风险与缓解

| 风险 | 概率 | 影响 | 缓解 |
|------|------|------|------|
| OpenClaw Gateway 不可用 | 中 | 高 | FallbackHandler 客户端侧降级 + 本地模型回退 |
| LLM 增强增加延迟 | 高 | 中 | 单次调用完成 rank+expand+summarize；可选关闭 |
| 100+ 源 Rate Limit | 中 | 中 | Coordinator 已有优先级+并发控制（v3.0.3） |
| 语义去重误删 | 低 | 中 | Jaccard 阈值可调；默认 0.8 保守 |
| 废弃 llm/ 破坏引用 | 低 | 高 | 全局 grep + 更新所有 import |
| LLM 成本过高 | 中 | 中 | CostOptimizer 预算控制 + ModelRouter 经济路由 |
