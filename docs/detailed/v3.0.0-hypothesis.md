### Edge Cases

- `rankingWeights` must sum to 1.0; if not, normalize proportionally
- `minHypotheses` ≤ `maxHypotheses`; swap if violated
- `Evidence.relevance` and `reliability` clamped to `[0.0, 1.0]`
- Duplicate evidence (same source + content) → deduplicated, keep higher relevance
- Empty statement → `ValidationIssue` with severity "error"

### Core Algorithm: `generate`

```
Input:  Evidence[], optional context
Output: Hypothesis[] (≥ minHypotheses, ≤ maxHypotheses)

1. Group evidence by domain/topic clusters:
   - Extract key terms from each evidence.content
   - Cluster evidence with shared key terms (Jaccard similarity > 0.3)
2. For each cluster with ≥ minEvidencePerHypothesis evidence:
   a. Generate candidate statements:
      - Causal: "X causes/affects/influences Y" from evidence pairs
      - Correlational: "X is associated with Y" from co-occurring terms
      - Explanatory: "X explains Y" from evidence with hierarchical terms
      - Predictive: "If X then Y" from temporal evidence sequences
      - Comparative: "X is more/less than Y" from quantitative evidence
   b. Compute initial confidence:
      - Average relevance of supporting evidence × average reliability
      - Cap at 0.9 (never absolute certainty)
   c. Set status = PROPOSED
3. If < minHypotheses generated:
   - Generate cross-cluster hypotheses (combine evidence from different clusters)
   - Lower minEvidencePerHypothesis to 1 for supplementary generation
4. If > maxHypotheses generated:
   - Keep top maxHypotheses by confidence
5. Return hypotheses sorted by confidence descending
```

### Evidence Clustering

```typescript
function clusterEvidence(evidence: Evidence[]): Evidence[][] {
  const clusters: Evidence[][] = [];
  const assigned = new Set<string>();

  for (const item of evidence) {
    if (assigned.has(item.id)) continue;
    const cluster: Evidence[] = [item];
    assigned.add(item.id);

    const terms = extractKeyTerms(item.content);
    for (const other of evidence) {
      if (assigned.has(other.id)) continue;
      const otherTerms = extractKeyTerms(other.content);
      const similarity = jaccardSimilarity(terms, otherTerms);
      if (similarity > 0.3) {
        cluster.push(other);
        assigned.add(other.id);
      }
    }
    clusters.push(cluster);
  }

  return clusters;
}

function jaccardSimilarity(a: string[], b: string[]): number {
  const setA = new Set(a);
  const setB = new Set(b);
  const intersection = new Set([...setA].filter(x => setB.has(x)));
  const union = new Set([...setA, ...setB]);
  return union.size === 0 ? 0 : intersection.size / union.size;
}
```

### Refinement Algorithm: `refineHypothesis`

```
Input:  Hypothesis, new Evidence[]
Output: Hypothesis (updated)

1. Classify new evidence as supporting or contradicting:
   - If evidence.relevance > 0.5 → supporting
   - Else → contradicting
2. Update confidence:
   - Each new supporting evidence: confidence += 0.05 (max 0.95)
   - Each new contradicting evidence: confidence -= 0.10 (min 0.05)
3. Update status:
   - confidence ≥ 0.7 → SUPPORTED
   - confidence < 0.3 → REFUTED
   - otherwise → INCONCLUSIVE
4. Update updatedAt timestamp
```

### Error Handling

- Empty evidence array → return empty array (not throw)
- All evidence with reliability 0 → hypotheses generated but confidence = minConfidence
- Single evidence item → generate 1 hypothesis (less than minHypotheses)
- Evidence content too short (< 10 chars) → skip, can't extract meaningful terms

### Edge Cases

- Two identical hypotheses generated → merge, combine evidence arrays
- Hypothesis statement > 500 chars → truncate to 500
- `combineHypotheses` with incompatible categories → return null
- `combineHypotheses` with same hypothesis → return clone

```typescript
): HypothesisRanker;
```

### Core Algorithm: `rank`

```
Input:  Hypothesis[]
Output: RankedHypothesis[] (sorted by score descending)

For each hypothesis:
1. Evidence support score = supportingEvidence.length / (supportingEvidence.length + contradictingEvidence.length)
   - If both 0 → 0.5 (neutral)
2. Evidence reliability score = average reliability of all evidence
3. Novelty score = 1.0 - (similarity to known facts) → computed via term overlap
4. Testability score = based on presence of measurable terms (numbers, percentages, comparatives)
5. Coherence score = internal consistency check:
   - No self-contradiction in statement
   - Evidence aligns with statement category
6. Composite score = weighted sum using RankingWeights:
   score = w1*evidenceSupport + w2*evidenceReliability + w3*novelty + w4*testability + w5*coherence
7. Assign strength label:
   - score ≥ 0.8 → STRONG
   - score ≥ 0.5 → MODERATE
   - score ≥ 0.3 → WEAK
   - score < 0.3 → NEGLIGIBLE
8. Sort by score descending, assign rank (1-based)
```

### Novelty Computation

```typescript
function computeNovelty(hypothesis: Hypothesis, allHypotheses: Hypothesis[]): number {
  const terms = extractKeyTerms(hypothesis.statement);
  if (terms.length === 0) return 0.5;

  let maxSimilarity = 0;
  for (const other of allHypotheses) {
    if (other.id === hypothesis.id) continue;
    const otherTerms = extractKeyTerms(other.statement);
    const similarity = jaccardSimilarity(terms, otherTerms);
    maxSimilarity = Math.max(maxSimilarity, similarity);
  }

  return 1.0 - maxSimilarity;
}
```

### Testability Scoring

```typescript
function computeTestability(statement: string): number {
  let score = 0.3; // base

  // Measurable terms increase testability
  if (/\d+%/.test(statement)) score += 0.2;
  if (/more than|less than|greater|higher|lower/i.test(statement)) score += 0.15;
  if (/causes?|affects?|influences?|leads? to/i.test(statement)) score += 0.15;
  if (/predicts?|forecasts?/i.test(statement)) score += 0.1;
  if (statement.includes("?")) score -= 0.2; // questions are less testable

  return Math.min(score, 1.0);
}
```

### Ranking Accuracy Target

Acceptance criteria: ≥ 80% accuracy. Accuracy is measured by comparing the top-ranked hypothesis against a ground-truth ranking (pre-labeled by domain experts on a test dataset). The ranker should place the "correct" (highest ground-truth) hypothesis in the top position ≥ 80% of the time.

### Error Handling

- Empty hypotheses array → return empty array
- All hypotheses with identical scores → stable sort preserves input order
- Negative or zero weights → normalize to 0.01 minimum to avoid division by zero

### Edge Cases

- Single hypothesis → always rank 1, score computed normally
- Hypothesis with no evidence → evidenceSupport = 0.5, score dominated by other factors
- Weights don't sum to 1.0 → normalize proportionally

### Core Algorithm: `validate`

```
Input:  Hypothesis
Output: ValidationResult

1. Feasibility check:
   - Statement is non-empty and meaningful (> 20 chars)
   - Has at least 1 supporting evidence OR 1 contradicting evidence
   - Category is a valid HypothesisCategory
   - Confidence is in [0, 1]

2. Testability check:
   - Statement contains measurable/comparable terms
   - Evidence contains quantitative data
   - Hypothesis is not purely speculative (confidence > 0.2)

3. Falsifiability check:
   - Statement can be proven false (not a tautology)
   - Contains specific claims, not vague generalizations
   - Check for falsifiability markers: "always", "never", "all", "none" → warning

4. Novelty check:
   - Compare against common knowledge patterns
   - High novelty: unusual term combinations, unexpected relations
   - Low novelty: commonly stated facts

5. Clarity check:
   - Statement length: 20–500 chars (ideal)
   - No ambiguous pronouns without clear referents
   - Category matches statement structure

6. Overall score = weighted average of feasibility, testability, falsifiability, novelty, clarity
   - Weight: 0.25 each

7. Collect issues: error if fails threshold, warning if marginal, info otherwise
```

### Falsifiability Detection

```typescript
function checkFalsifiability(statement: string): {
  falsifiable: boolean;
  issues: ValidationIssue[];
} {
  const issues: ValidationIssue[] = [];

  // Tautology patterns (unfalsifiable)
  const tautologyPatterns = [
    /either.*or.*not/i,
    /what is.*is/i,
    /it is what it is/i,
  ];
  for (const pattern of tautologyPatterns) {
    if (pattern.test(statement)) {
      issues.push({
        severity: "warning",
        message: "Statement appears tautological and may be unfalsifiable",
      });
      return { falsifiable: false, issues };
    }
  }

  // Absolute claims warning
  if (/\b(always|never|all|none|every|no one)\b/i.test(statement)) {
    issues.push({
      severity: "warning",
      message: "Absolute claims are difficult to verify; consider qualifying",
    });
  }

  return { falsifiable: issues.length === 0, issues };
}
```

### Error Handling

- Empty statement → `feasible: false`, overallScore: 0, issues: [error]
- Null/undefined hypothesis → throw `TypeError`
- Hypothesis with future `createdAt` date → warning issue, not error

### Edge Cases

- Very long statement (>1000 chars) → clarity score reduced, truncation warning
- Statement in non-English language → processed normally, no language check
- Statement with only stop words → clarity score near 0

## 6. Module 5: Index & Engine (`src/hypothesis/index.ts`)

### Exports

```typescript
export * from "./types.js";
export * from "./generator.js";
export * from "./ranker.js";
export * from "./validator.js";

export interface HypothesisEngineConfig {
  generator?: Partial<HypothesisConfig>;
  ranker?: Partial<HypothesisConfig>;
  validator?: Partial<HypothesisConfig>;
}

export class HypothesisEngine {
  private generator: HypothesisGenerator;
  private ranker: HypothesisRanker;
  private validator: HypothesisValidator;

  constructor(config?: HypothesisEngineConfig);

  // Generation (delegated)
  generate(evidence: Evidence[]): Hypothesis[];

  // Ranking (delegated)
  rank(hypotheses: Hypothesis[]): RankedHypothesis[];

  // Validation (delegated)
  validate(hypothesis: Hypothesis): ValidationResult;

  // Combined pipeline
  generateAndRank(evidence: Evidence[]): RankedHypothesis[];
  generateRankAndValidate(evidence: Evidence[]): {
    ranked: RankedHypothesis[];
    validations: Map<string, ValidationResult>;
  };

  getStats(): {
    totalGenerated: number;
    totalRanked: number;
    totalValidated: number;
  };
}

export function createHypothesisEngine(
  config?: HypothesisEngineConfig,
): HypothesisEngine;
```

### Combined Pipeline: `generateRankAndValidate`

```
1. hypotheses = generator.generate(evidence)
2. ranked = ranker.rank(hypotheses)
3. validations = new Map(ranked.map(r => [r.hypothesis.id, validator.validate(r.hypothesis)]))
4. Filter out hypotheses that fail validation (overallScore < threshold)
5. Return { ranked: filtered, validations }
```

## 8. Data Flow

```
Evidence[] (from search/extraction)
       │
       ▼
HypothesisGenerator.generate()
  ├── Cluster evidence by key terms
  ├── Generate statements per category
  └── Compute initial confidence
       │
       ▼
Hypothesis[] (≥ 3, ≤ 10)
       │
       ▼
HypothesisRanker.rank()
  ├── Evidence support score
  ├── Reliability score
  ├── Novelty score
  ├── Testability score
  ├── Coherence score
  └── Composite weighted score
       │
       ▼
RankedHypothesis[] (sorted by score)
       │
       ▼
HypothesisValidator.validate()
  ├── Feasibility
  ├── Testability
  ├── Falsifiability
  ├── Novelty
  └── Clarity
       │
       ▼

       │
       ▼
Downstream: ExperimentalDesign.design(hypothesis)
```
