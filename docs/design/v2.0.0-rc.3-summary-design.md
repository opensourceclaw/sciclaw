## 1. Overview

### 1.1 Objective

Implement multi-agent collaboration system, evaluation benchmarks, and documentation for the final rc release before v2.0.0 stable.

### 1.2 Scope

| Area | Description |
|------|-------------|
| **Multi-Agent System** | 4 specialized agents with communication protocol and task distribution |
| **Benchmark & Evaluation** | 10+ benchmark tasks, quality metrics, comparative analysis |
| **Documentation** | API docs, user guides, examples, migration guides |

### 1.3 Design Principles

- **Composable agents**: Each agent is independently testable, communicates via typed messages
- **Leverage existing modules**: Multi-agent system consumes rc.2's knowledge graph, validation, NLP
- **Test-driven**: Benchmarks are executable tests, not just metrics
- **English-only**: All code, docs, comments in English

## 3. Interface Definitions

### 3.1 Agent Types (`src/agents/types.ts`)

```typescript
// ── Agent Identity ──
export enum AgentRole {
  PLANNING = "planning",
  SEARCH = "search",
  SYNTHESIS = "synthesis",
  WRITING = "writing",
}

export interface AgentConfig {
  role: AgentRole;
  name: string;
  capabilities: string[];
  maxRetries: number;
  timeoutMs: number;
}

// ── Message Protocol ──
export enum MessageType {
  TASK = "task",
  RESULT = "result",
  QUERY = "query",
  ERROR = "error",
  STATUS = "status",
}

export interface AgentMessage {
  id: string;
  type: MessageType;
  from: AgentRole;
  to: AgentRole | "orchestrator";
  taskId: string;
  payload: unknown;
  timestamp: Date;
  correlationId?: string;     // for request-response pairing
}

// ── Task Distribution ──
export interface AgentTask {
  id: string;
  role: AgentRole;
  action: string;              // what to do
  input: unknown;              // input data
  context?: Record<string, unknown>;  // shared context
  priority: number;            // 0 (lowest) - 10 (highest)
  deadline?: Date;
}

export interface AgentResult {
  taskId: string;
  role: AgentRole;
  status: "success" | "partial" | "failed";
  output: unknown;
  artifacts: string[];         // file paths, URLs, etc.
  metrics: {
    durationMs: number;
    tokenCount?: number;
    toolCalls?: number;
  };
  errors: string[];
}

// ── Orchestration ──
export interface OrchestrationPlan {
  id: string;
  topic: string;
  phases: OrchestrationPhase[];
  createdAt: Date;
}

export interface OrchestrationPhase {
  order: number;
  name: string;
  agents: AgentRole[];
  dependencies: number[];      // phase orders that must complete first
  timeoutMs: number;
}

export interface OrchestrationResult {
  planId: string;
  topic: string;
  phases: {
    order: number;
    name: string;
    results: AgentResult[];
    durationMs: number;
    status: "success" | "partial" | "failed";
  }[];
  aggregatedOutput: unknown;
  totalDurationMs: number;
  overallStatus: "success" | "partial" | "failed";
}
```

## 4. Module Specifications

### 4.1 `base_agent.ts`

**Purpose**: Abstract base class for all agents.

**Key exports**:
- `abstract class BaseAgent`
  - `config: AgentConfig`
  - `abstract execute(task: AgentTask): Promise<AgentResult>`
  - `sendMessage(msg: AgentMessage): void`
  - `receiveMessage(): AgentMessage | null`
  - `getStatus(): { role, busy, queueSize }`

**Message queue**: In-memory FIFO per agent, consumed by orchestrator.

### 4.2 `orchestrator.ts`

**Purpose**: Task distribution, phase sequencing, result aggregation.

**Key exports**:
- `class Orchestrator`
  - `registerAgent(agent: BaseAgent): void`
  - `createPlan(topic: string): OrchestrationPlan`
  - `executePlan(plan: OrchestrationPlan): Promise<OrchestrationResult>`
  - `sendMessage(msg: AgentMessage): void`
  - `getAgentStatuses(): Map<AgentRole, AgentStatus>`

**Default phases** (sequential with dependencies):

| Phase | Agents | Depends On | Description |
|-------|--------|:--:|-------------|
| 1. Plan | Planning | - | Generate research plan, queries, subtopics |
| 2. Search | Search | 1 | Execute searches, extract content |
| 3. Synthesize | Synthesis | 2 | Cross-reference, validate, build knowledge graph |
| 4. Write | Writing | 3 | Generate final report with citations |

### 4.3 `planning_agent.ts`

**Purpose**: Generate research plans from topics.

**Key exports**:
- `class PlanningAgent extends BaseAgent`
  - `execute(task): Promise<AgentResult>`
  - Output: `{ topic, subtopics, queries, depth, strategy }`

**Strategy**: Uses `src/research/` module + NLP (NER/relation) to decompose topic into subtopics and search queries.

### 4.4 `search_agent.ts`

**Purpose**: Execute searches and extract content.

**Key exports**:
- `class SearchAgent extends BaseAgent`
  - `execute(task): Promise<AgentResult>`
  - Output: `{ sources, extractedContent, metadata }`

**Strategy**: Uses `src/search/` + `src/extractor/` + `src/tools/`. Applies source scoring and citation tracking from rc.2 validation module.

### 4.5 `synthesis_agent.ts`

**Purpose**: Cross-reference sources, validate claims, build knowledge graph.

**Key exports**:
- `class SynthesisAgent extends BaseAgent`
  - `execute(task): Promise<AgentResult>`
  - Output: `{ knowledgeGraph, validatedClaims, crossReferences, contradictions }`

**Strategy**: Uses `src/knowledge/` (graph_builder) + `src/validation/` (claim_extractor, factcheck_service, risk_scorer) + `src/llm/` (synthesize).

### 4.6 `writing_agent.ts`

**Purpose**: Generate final research report with citations.

**Key exports**:
- `class WritingAgent extends BaseAgent`
  - `execute(task): Promise<AgentResult>`
  - Output: `{ report, citations, sections, format }`

**Strategy**: Uses `src/report/` + `src/validation/citation_formatter.ts`. Formats citations in APA/MLA/Chicago as configured.

### 4.7 Benchmark Module (`src/benchmark/`)

#### `runner.ts`
- `class BenchmarkRunner`
  - `registerTask(task: BenchmarkTask): void`
  - `runAll(): Promise<BenchmarkReport>`
  - `runCategory(category: string): Promise<BenchmarkResult[]>`
  - `runTask(taskId: string): Promise<BenchmarkResult>`

#### `metrics.ts`
- `computeFactuality(result, expectedFacts): number` — claim overlap ratio
- `computeCompleteness(result, expectedSources): number` — source coverage
- `computeCitationQuality(result): number` — citation format validity
- `computeReasoningDepth(result): number` — multi-hop chain count
- `computeOverall(scores, weights): number` — weighted average

#### `reporter.ts`
- `generateReport(results): BenchmarkReport`
- `formatMarkdown(report): string`
- `formatJSON(report): string`
- `compareReports(baseline, current): ComparisonReport`
