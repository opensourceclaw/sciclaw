## 1. 项目概述

### 1.1 背景

DeepClaw 当前为 **Python + TypeScript 混合代码**，与 OpenClaw 生态其他项目（devclaw 已 100% TS）技术栈不一致。

根据 ADR-001 技术决策，需要统一技术栈为 TypeScript。

### 1.2 目标

将 DeepClaw 从 63% TypeScript 提升至 **100% TypeScript**，移除所有 Python 遗留代码。

| **src/** | 129 | 70 | 199 | 65% |

## 4. 技术方案

### 4.1 转换策略

1. **手动转换为主**: 复杂业务逻辑需要人工重写
2. **保留测试覆盖**: 每个 Python 测试对应转换为 TS 测试
3. **逐模块迁移**: 按模块迁移，保持功能可运行
4. **CI 验证**: 每次 PR 自动构建 + 测试

### 4.2 模块依赖关系

```
llm/ (providers)
    ↓
tools/ (web_search, content_extraction)
    ↓
research/ (planner, runner, synthesizer)
    ↓
summarization/
    ↓
CLI / API
```

**迁移顺序**: 从底层 (llm) 到上层 (cli/api)

## 5. 风险与约束

### 5.1 风险
