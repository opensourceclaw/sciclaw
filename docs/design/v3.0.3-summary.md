## 🏗️ Architecture

### 1. 并行搜索引擎 (Parallel Search Engine)

```
User Query
    │
    ▼
┌─────────────────────────────┐
│   Search Orchestrator      │
│   (SearchCoordinator)      │
└─────────────────────────────┘
    │
    ├──▶ Search Source 1 (concurrent)
    ├──▶ Search Source 2 (concurrent)
    ├──▶ ...
    └──▶ Search Source N (concurrent)
    │
    ▼
┌─────────────────────────────┐
│   Result Aggregator        │
│   (merge + rank)           │
└─────────────────────────────┘
    │
    ▼
Streaming Results
```

**核心类**:
- `SearchCoordinator`: 并发调度器，管理搜索任务
- `SearchSource`: 搜索源接口
- `ResultAggregator`: 结果聚合器

### 2. 请求批处理 (Request Batching)

**目标**: 减少网络往返次数

```typescript
interface BatchQueue<T> {
  enqueue(request: T): Promise<T>;
  flush(): Promise<T[]>;
}
```

### 3. 连接池 (Connection Pooling)

```typescript
interface ConnectionPool {
  acquire(): Promise<Connection>;
  release(conn: Connection): void;
}
```

**实现**:
- 使用 `fetch` with `keepalive` 
- 或使用 `undici` 连接池

### 4. 流式返回 (Streaming)

```typescript
interface SearchStream {
  onResult(callback: (result: SearchResult) => void): void;
  onComplete(callback: (stats: SearchStats) => void): void;
  cancel(): void;
}
```

### 5. 性能指标 (Metrics)

```typescript
interface PerformanceMetrics {
  recordLatency(source: string, latencyMs: number): void;
  getPercentiles(): { p50: number; p95: number; p99: number };
  getThroughput(): number; // searches/sec
}
```
