## 3. 反馈模块 (`feedback/`)

### 3.1 FeedbackCollector (`collector.ts`)

**职责**: 收集用户反馈

```typescript
export class FeedbackCollector {
  private history: UserFeedback[];
  private options: FeedbackCollectorOptions;

  constructor(options?: Partial<FeedbackCollectorOptions>);

  /** 收集反馈 */
  collect(type: FeedbackType, content: string, target?: string): UserFeedback;

  /** 批量收集 */
  collectBatch(inputs: Array<{ type: FeedbackType; content: string; target?: string }>): UserFeedback[];

  /** 获取历史 */
  getHistory(limit?: number): UserFeedback[];

  /** 按类型过滤 */
  getByType(type: FeedbackType): UserFeedback[];

  /** 清空历史 */
  clear(): void;

  /** 统计 */
  stats(): { total: number; byType: Record<FeedbackType, number> };
}
```

**核心逻辑**:
- 生成唯一 ID（随机字符串）
- 校验 feedbackType 合法性
- 校验 content 非空
- 超出 maxHistory 时移除最早的记录

**边界条件**:

| 场景 | 处理 |
|------|------|
| content 为空 | 抛出 Error |
| 非法 feedbackType | 抛出 Error |
| 超出 maxHistory | FIFO 移除最旧记录 |

### 3.2 FeedbackProcessor (`processor.ts`)

**职责**: 将用户反馈转换为可执行调整指令

```typescript
export class FeedbackProcessor {
  constructor();

  /** 处理单条反馈 */
  process(feedback: UserFeedback): ProcessedFeedback;

  /** 批量处理 */
  processBatch(feedbacks: UserFeedback[]): ProcessedFeedback[];

  /** 合并多条处理结果 */
  merge(processed: ProcessedFeedback[]): {
    action: ProcessedFeedback['action'];
    adjustments: string[];
    priority: number;
  };
}
```

**类型→动作映射**:

| FeedbackType | Action | Priority | Adjustments 生成 |
|-------------|--------|----------|-----------------|
| positive | continue | 0.3 | 保持当前方向 |
| negative | redirect | 0.8 | 生成反向调整指令 |
| modify | refine | 0.7 | 提取修改要点 |
| supplement | expand | 0.6 | 提取补充关键词 |
| pause | halt | 1.0 | 停止信号 |

**边界条件**:

| 场景 | 处理 |
|------|------|
| 空 feedback content | action=continue, priority=0 |
| 未知 feedbackType | 降级为 continue |

## 4. 查询优化模块 (`query_optimizer/`)

### 4.1 QueryRewriter (`rewriter.ts`)

**职责**: 根据用户反馈重写查询

```typescript
export class QueryRewriter {
  private rules: RewriteRule[];

  constructor();

  /** 重写单条查询 */
  rewrite(query: string, feedback: ProcessedFeedback): string[];

  /** 批量重写 */
  rewriteBatch(queries: string[], feedbacks: ProcessedFeedback[]): string[];

  /** 添加重写规则 */
  addRule(rule: RewriteRule): void;

  /** 获取内置规则 */
  getDefaultRules(): RewriteRule[];
}
```

**内置重写规则**:

| 模式 | 替换 | 说明 |
|------|------|------|
| /too (broad\|vague\|general)/i | more specific | 模糊→具体 |
| /not enough (detail\|depth)/i | in-depth analysis | 深度不足 |
| /wrong (direction\|focus\|approach)/i | alternative perspective | 方向错误 |
| /focus on (.*)/i | $1 detailed | 聚焦特定方面 |

**处理流程**:
1. 根据 feedback.action 选择规则集
2. 对每条规则尝试匹配
3. 生成 1-3 条重写后的查询
4. 去重后返回

### 4.2 QueryExpander (`expander.ts`)

**职责**: 扩展查询以覆盖更多相关领域

```typescript
export class QueryExpander {
  private synonymMap: Map<string, string[]>;

  constructor();

  /** 扩展查询 */
  expand(query: string, maxExpansions?: number): ExpansionResult;

  /** 批量扩展 */
  expandBatch(queries: string[], maxExpansions?: number): ExpansionResult[];

  /** 添加同义词 */
  addSynonym(term: string, synonyms: string[]): void;

  /** 获取默认同义词 */
  getDefaultSynonyms(): Map<string, string[]>;
}
```

**默认同义词库**:

| 术语 | 同义词 |
|------|--------|
| AI | artificial intelligence, machine learning |
| performance | efficiency, throughput, latency |
| security | safety, protection, vulnerability |
| database | storage, persistence, data store |
| network | connectivity, communication, protocol |

**处理流程**:
1. 分词
2. 对每个词查找同义词
3. 生成扩展组合（同义词替换/添加）
4. 按相关性评分排序
5. 截取 maxExpansions 条

### 4.3 QueryScheduler (`scheduler.ts`)

**职责**: 调度查询执行顺序

```typescript
export class QueryScheduler {
  constructor();

  /** 调度查询 */
  schedule(queries: Query[]): ScheduleResult;

  /** 更新查询优先级 */
  updatePriority(queryId: string, newPriority: number): void;

  /** 获取下一个待执行查询 */
  next(): Query | null;

  /** 标记查询完成 */
  complete(queryId: string, score: number): void;

  /** 获取待处理查询数 */
  get pendingCount(): number;
}
```

**调度算法**:
- 按 priority 降序排列
- 相同 priority 按 createdAt 升序（FIFO）
- source='expanded' 的查询优先级减 0.1（扩展查询权重略低）
- 检测完全相同的查询文本，保留高优先级者

**边界条件**:

| 场景 | 处理 |
|------|------|
| 空查询列表 | 返回空 ScheduleResult |
| 所有查询 priority=0 | 按 FIFO 顺序 |
| 重复查询 | 保留高优先级，标记低优先级为 skipped |

## 5. 渐进式构建模块 (`progressive/`)

### 5.1 SectionSegmenter (`segmenter.ts`)

**职责**: 将报告拆分为可独立构建的章节

```typescript
export class SectionSegmenter {
  private options: SegmenterOptions;

  constructor(options?: Partial<SegmenterOptions>);

  /** 分割报告 */
  segment(topic: string, outline?: string[]): Section[];

  /** 重新分割（用户反馈后） */
  resegment(sections: Section[], feedback: ProcessedFeedback): Section[];

  /** 检测章节依赖 */
  detectDependencies(sections: Section[]): Section[];
}
```

**分割算法**:
1. 无 outline 时，基于 topic 类型生成默认章节模板
2. 有 outline 时，每项作为一个 Section
3. 自动检测依赖：引言无依赖，方法依赖引言，结果依赖方法，结论依赖所有
4. 不超过 maxSections 限制

**默认章节模板**:

| 报告类型 | 章节 |
|---------|------|
| research | introduction, methodology, results, discussion, conclusion |
| technical | overview, architecture, implementation, evaluation, conclusion |
| analysis | background, data, analysis, findings, recommendations |

### 5.2 ProgressiveBuilder (`builder.ts`)

**职责**: 增量构建报告章节

```typescript
export class ProgressiveBuilder {
  private results: Map<string, SectionResult>;
  private options: BuilderOptions;

  constructor(options?: Partial<BuilderOptions>);

  /** 构建单个章节 */
  async build(section: Section, context?: string): Promise<SectionResult>;

  /** 并行构建多个章节 */
  async buildBatch(sections: Section[]): Promise<SectionResult[]>;

  /** 重构建指定章节 */
  async rebuild(sectionId: string): Promise<SectionResult>;

  /** 获取已构建结果 */
  getResult(sectionId: string): SectionResult | undefined;

  /** 获取所有结果 */
  getAllResults(): SectionResult[];
}
```

**构建流程**:
1. 检查依赖是否全部完成
2. 收集已完成依赖章节的内容作为上下文
3. 调用 LLMEngine 生成章节内容
4. 计算 wordCount 和 confidence
5. 缓存结果

**依赖管理**:
- 构建前检查所有依赖的 status === 'completed'
- 依赖未满足时抛出明确错误
- 重建某个章节时，标记其下游章节为 pending

### 5.3 PreviewGenerator (`preview.ts`)

**职责**: 生成中间预览

```typescript
export class PreviewGenerator {
  constructor();

  /** 生成预览 */
  generate(results: SectionResult[], totalSections: number): ProgressPreview;

  /** 估算剩余时间 */
  estimateRemaining(completed: number, total: number, elapsedMs: number): number;

  /** 生成预览摘要 */
  generateSummary(results: SectionResult[]): string;
}
```

**估算算法**:
- 已完成章节的平均耗时 × 剩余章节数
- 并行模式：平均耗时 × (剩余章节数 / 并行数)
- 最小估值：5 秒

## 7. InteractiveEngine 主导出 (`index.ts`)

```typescript
import { FeedbackCollector } from './feedback/collector.js';
import { FeedbackProcessor } from './feedback/processor.js';
import { QueryRewriter } from './query_optimizer/rewriter.js';
import { QueryExpander } from './query_optimizer/expander.js';
import { QueryScheduler } from './query_optimizer/scheduler.js';
import { SectionSegmenter } from './progressive/segmenter.js';
import { ProgressiveBuilder } from './progressive/builder.js';
import { PreviewGenerator } from './progressive/preview.js';
import { ProgressTracker } from './visualization/progress.js';
import { StatusDisplay } from './visualization/status.js';

export class InteractiveEngine {
  private feedbackCollector: FeedbackCollector;
  private feedbackProcessor: FeedbackProcessor;
  private queryRewriter: QueryRewriter;
  private queryExpander: QueryExpander;
  private queryScheduler: QueryScheduler;
  private segmenter: SectionSegmenter;
  private builder: ProgressiveBuilder;
  private previewGenerator: PreviewGenerator;
  private progressTracker: ProgressTracker;
  private statusDisplay: StatusDisplay;
  private config: InteractiveConfig;

  constructor(config?: Partial<InteractiveConfig>);

  /** 运行完整交互式研究 */
  async run(topic: string, options?: { outline?: string[]; feedbacks?: UserFeedback[] }): Promise<InteractiveResult>;

  /** 收集反馈 */
  collectFeedback(type: FeedbackType, content: string, target?: string): UserFeedback;

  /** 处理反馈并调整 */
  async processFeedback(feedback: UserFeedback): Promise<ProcessedFeedback>;

  /** 优化查询 */
  async optimizeQueries(queries: string[], feedbacks?: ProcessedFeedback[]): Promise<Query[]>;

  /** 构建章节 */
  async buildSection(section: Section): Promise<SectionResult>;

  /** 获取预览 */
  getPreview(): ProgressPreview;

  /** 获取进度 */
  getProgress(): ResearchProgress;
}
```

**run() 流程**:
```
1. 分割报告章节 (segmenter.segment)
2. 初始化进度跟踪 (progressTracker)
3. 循环：
   a. 选择下一个可构建的章节
   b. 收集用户反馈（可选）
   c. 处理反馈 → 优化查询（可选）
   d. 构建章节
   e. 更新进度
   f. 生成预览
4. 返回 InteractiveResult
```
