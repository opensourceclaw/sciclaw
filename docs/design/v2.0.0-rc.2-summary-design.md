## 1. Overview

### 1.1 Objective

Migrate Python validation modules to TypeScript and build a new Knowledge Graph module, completing the rc.2 scope: Knowledge Graph + Citation Management + Source Credibility + Confidence Assessment + Stability.

### 1.2 Scope

| Module | Source | Approach |
|--------|--------|----------|
| `src/validation/` | Python `src/deepclaw/validation/` | Migrate 6 modules (~3900 lines) |
| `src/knowledge/` | New | Build from scratch |
| `src/index.ts` | Existing | Add exports |

### 1.3 Design Principles

- **Interface-first**: Define TypeScript interfaces before implementation
- **Zero Python dependency**: No bridging to Python validation code
- **Test-driven**: Each module must have corresponding tests
- **Backward compatible**: Existing TS exports unchanged

## 3. Interface Definitions

### 3.1 Validation Types (`src/validation/types.ts`)

```typescript
// ── Claim Types ──
export enum ClaimType {
  FACTUAL = "factual",
  NUMERIC = "numeric",
  QUOTATION = "quotation",
  COMPARISON = "comparison",
  CAUSATION = "causation",
  OPINION = "opinion",
}

export interface NumericClaim {
  value: number;
  unit: string;
  context: string;
  position: number;
  originalText: string;
}

export interface Claim {
  id: string;
  text: string;
  type: ClaimType;
  confidence: number;
  position: number;        // char offset in source
  sourceUrl?: string;
  numericData?: NumericClaim;
  metadata: Record<string, unknown>;
}

// ── Source Scoring ──
export interface DomainScore {
  domain: string;
  reputation: number;       // 0–1
  category: string;         // academic, government, news, etc.
}

export interface FreshnessScore {
  score: number;            // 0–1
  daysSincePublished: number;
  publishedDate?: Date;
}

export interface SourceScore {
  domain: DomainScore;
  freshness: FreshnessScore;
  authority: AuthorityScore;
  overall: number;          // Domain×0.4 + Freshness×0.3 + Authority×0.3
}

// ── Authority Scoring ──
export interface AuthorityScore {
  score: number;            // 0–1
  authorName?: string;
  institution?: string;
  citationCount?: number;
  hasCredentials: boolean;
}

// ── Risk Scoring ──
export enum RiskLevel {
  LOW = "LOW",
  MEDIUM = "MEDIUM",
  HIGH = "HIGH",
  CRITICAL = "CRITICAL",
}

export interface RiskAssessment {
  claim: Claim;
  sourceScore: number;      // 0–1
  claimTypeRisk: number;    // 0–1
  verificationScore: number; // 0–1
  overallRisk: number;      // Source×0.3 + Claim×0.3 + Verify×0.4
  level: RiskLevel;
}

// ── Citation ──
export interface Citation {
  url: string;
  title: string;
  sourceId: string;
  domain: string;
  publishedDate?: Date;
  accessedDate: Date;
  qualityScore: number;
  relevantSnippet: string;
  author?: string;
  siteName?: string;
  metadata: Record<string, unknown>;
}

export enum CitationStyle {
  APA = "apa",
  MLA = "mla",
  CHICAGO = "chicago",
}

// ── Fact-Check ──
export enum VerificationStatus {
  VERIFIED = "verified",
  FALSE = "false",
  PARTIALLY_TRUE = "partially_true",
  UNVERIFIABLE = "unverifiable",
  PENDING = "pending",
}

export interface VerificationResult {
  claim: Claim;
  status: VerificationStatus;
  confidence: number;
  sourceCount: number;
  supportingSources: number;
  contradictingSources: number;
  checkedAt: Date;
  notes: string;
}
```

### 3.2 Knowledge Graph Types (`src/knowledge/types.ts`)

```typescript
export interface GraphNode {
  id: string;
  label: string;            // entity text
  type: string;             // PERSON, ORG, LOC, CONCEPT, etc.
  properties: Record<string, unknown>;
  confidence: number;       // 0–1
  sources: string[];        // source URLs
}

export interface GraphEdge {
  id: string;
  sourceId: string;         // node id
  targetId: string;         // node id
  type: string;             // WORKS_FOR, LOCATED_IN, RELATED_TO, etc.
  label: string;
  confidence: number;
  properties: Record<string, unknown>;
  sources: string[];
}

export interface KnowledgeGraph {
  nodes: Map<string, GraphNode>;
  edges: Map<string, GraphEdge>;
  adjacencyList: Map<string, Set<string>>;  // nodeId → connected nodeIds
}

export interface GraphQuery {
  nodeTypes?: string[];
  edgeTypes?: string[];
  minConfidence?: number;
  maxDepth?: number;
}

export interface Subgraph {
  nodes: GraphNode[];
  edges: GraphEdge[];
}
```

## 4. Module Specifications

### 4.1 `claim_extractor.ts`

**Purpose**: Detect and classify factual claims in text.

**Key exports**:
- `extractClaims(text: string, sourceUrl?: string): Claim[]`
- `extractNumericClaims(text: string): NumericClaim[]`

**Claim detection patterns** (6 types):
| Type | Detection Strategy |
|------|-------------------|
| FACTUAL | Declarative sentences with verifiable predicates |
| NUMERIC | Regex: numbers + units/percentages/currencies |
| QUOTATION | Quoted text blocks |
| COMPARISON | Comparative adjectives + "than" |
| CAUSATION | Causal connectors (because, therefore, leads to) |
| OPINION | Subjective markers (I think, arguably, should) |

### 4.2 `source_scorer.ts`

**Purpose**: Score source quality by domain reputation + content freshness.

**Key exports**:
- `scoreDomain(url: string): DomainScore`
- `scoreFreshness(date: string | Date): FreshnessScore`
- `scoreSource(url: string, publishedDate?: string): SourceScore`

**Domain reputation DB**: ~60 known domains (academic, government, news, tech).

**Formula**: `overall = domain.reputation × 0.4 + freshness.score × 0.3 + authority.score × 0.3`

### 4.3 `authority_scorer.ts`

**Purpose**: Score author credibility based on institution and citation metrics.

**Key exports**:
- `scoreAuthority(author?: string, institution?: string, citationCount?: number): AuthorityScore`

**Known institutions DB**: ~50 institutions (universities, research labs, companies).

### 4.4 `risk_scorer.ts`

**Purpose**: Multi-factor risk assessment for claims.

**Key exports**:
- `assessRisk(claim: Claim, sourceScore: number, verificationScore?: number): RiskAssessment`
- `getRiskLevel(score: number): RiskLevel`

**Formula**: `Risk = SourceScore × 0.3 + ClaimTypeRisk × 0.3 + VerificationScore × 0.4`

**Thresholds**: LOW < 0.25, MEDIUM < 0.45, HIGH < 0.65, CRITICAL ≥ 0.65

### 4.5 `citation_tracker.ts`

**Purpose**: Track all sources used during research with full metadata.

**Key exports**:
- `class CitationTracker` — add, get, list, search, export citations
- `createCitation(url, title, snippet?): Citation`

**Features**: Auto domain extraction, source ID generation, serialization, dedup by URL.

### 4.6 `citation_formatter.ts`

**Purpose**: Format citations in APA 7th, MLA 9th, Chicago 17th.

**Key exports**:
- `class CitationFormatter(style: CitationStyle)`
- `formatBibliography(citation: Citation): string`
- `formatInText(citation: Citation): string`

**Formats**:
| Style | In-Text | Bibliography |
|-------|---------|-------------|
| APA | (Author, Year) | Author. (Year). Title. Source. URL |
| MLA | (Author) | Author. "Title." Source, Year. URL |
| Chicago | Author, Title (Year) | Author. "Title." Source, Year. URL. |

### 4.7 `factcheck_service.ts`

**Purpose**: Cross-verify claims against multiple sources with caching.

**Key exports**:
- `class FactCheckService`
- `verifyClaim(claim: Claim, sources: string[]): Promise<VerificationResult>`
- `verifyClaims(claims: Claim[], sources: string[]): Promise<VerificationResult[]>`

**Features**: Cache with TTL, cross-source comparison, confidence scoring.

### 4.8 Knowledge Graph (`src/knowledge/`)

#### `graph_builder.ts`
- `buildGraph(entities: Entity[], relations: Relation[]): KnowledgeGraph`
- `mergeGraphs(graphs: KnowledgeGraph[]): KnowledgeGraph`
- `addToGraph(graph: KnowledgeGraph, entities: Entity[], relations: Relation[]): KnowledgeGraph`

#### `graph_store.ts`
- `class GraphStore` — CRUD for nodes/edges, adjacency index
- `getNode(id: string): GraphNode | undefined`
- `getEdge(id: string): GraphEdge | undefined`
- `upsertNode(node: GraphNode): void`
- `upsertEdge(edge: GraphEdge): void`
- `removeNode(id: string): boolean`
- `getStats(): { nodeCount, edgeCount }`

#### `graph_query.ts`
- `getNeighbors(nodeId: string, query?: GraphQuery): Subgraph`
- `findPath(fromId: string, toId: string, maxDepth?: number): GraphEdge[] | null`
- `querySubgraph(query: GraphQuery): Subgraph`
- `searchNodes(labelPattern: string): GraphNode[]`
