## Development Scope

### Task 1: Create DeepResearchFlow Class

**File**: `src/flows/deep_research_flow.ts`

**Requirements**:
```typescript
export class DeepResearchFlow {
  // Interactive mode - human approval required
  // Depth-first research strategy
  // Step-by-step with explicit confirmation
  
  async start(topic: string): Promise<void>;
  async plan(): Promise<ResearchPlan>;
  async search(): Promise<SearchResult[]>;
  async analyze(): Promise<AnalysisResult>;
  async synthesize(): Promise<SynthesisResult>;
  async report(): Promise<ResearchReport>;
  
  // Gate: Human approval at each major step
  async requestApproval(step: string): Promise<boolean>;
}
```

**Key Differences from AutoResearchFlow**:
| Aspect | DeepResearchFlow | AutoResearchFlow |
|--------|------------------|------------------|
| **Mode** | Interactive | Autonomous |
| **Strategy** | Depth-first | Breadth-first |
| **Approval** | Human approval required | Auto-approved |
| **Speed** | Slower (thoughtful) | Faster (automated) |
| **Use Case** | Complex research | Quick research |

### Task 2: Add CLI Mode Flag

**File**: `src/cli/index.ts`

**Requirements**:
```typescript
program
  .option('--mode <mode>', 'Research mode: deep | auto', 'deep')
  .action(async (options) => {
    if (options.mode === 'deep') {
      const flow = new DeepResearchFlow();
      await flow.start(topic);
    } else if (options.mode === 'auto') {
      const flow = new AutoResearchFlow();
      await flow.start(topic);
    }
  });
```

**CLI Usage**:
```bash
# Deep research (default)
deepclaw research "AI safety"

# Auto research
deepclaw research "AI safety" --mode auto
```
